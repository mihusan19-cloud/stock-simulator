# ORBIT 星軌交易所

費用限制：僅使用本機及免費工具，不購買任何產品、不開通付費伺服器或其他付費服務。

從零開發、預設離線單機遊玩的繁體中文虛擬股票交易平台，沒有使用 Hiteex 的程式碼。

## 啟動

需要 Python 3.11 或以上版本，無須安裝第三方套件。Windows 雙擊 `start.bat`，或在專案目錄執行：

```powershell
python server.py
```

開啟 http://localhost:8088 ，點選「登入 / 註冊」，再選「建立帳號」。每個帳號初始資金為 1,000,000 虛擬 TWD。

## 離線單機模式

在這台電腦開啟 http://localhost:8088 即可遊玩。啟動檔 start.bat 固定使用 127.0.0.1:8088，只接受本機連線，其他裝置無法連入。不需要網際網路、GitHub 或 Supabase。帳號、持倉與交易紀錄保存在 data/market.db；遊玩期間請保持伺服器程式運作。關閉程式或電腦休眠時，行情停止推進，重新啟動不補算中斷期間的行情。

此版本尚未部署至網際網路。跨地點使用需另行部署至有持久磁碟的主機，配置 HTTPS 反向代理，並設定 `COOKIE_SECURE=1`。正式公開前需補上登入速率限制、帳號復原、監控與備份，並依預期人數壓測。現有驗證涵蓋少量並行操作，未宣稱大型併發容量。

## 已實作

- 帳號註冊、登入、登出；scrypt 密碼雜湊與 HttpOnly 工作階段 Cookie。
- 六家虛構公司，全玩家共用伺服器行情，每三秒更新；一分鐘 K 線與折線圖。
- 市價、限價、取消委託；限價掛單保留資金或股數。
- 持倉、平均成本、未實現損益、最近交易紀錄。
- 自選清單、股票搜尋、總資產排行榜。
- SQLite 持久化；交易採資料庫交易與寫入鎖，避免並行超額支出。
- 響應式繁體中文柔和粉彩淺色介面，不依賴外部字型、CDN 或行情 API。

## 模擬規則

所有股票、價格及資金皆為虛構，不涉及真實金流。行情由本機伺服器每三秒自動更新，不需要下單才會波動；每次隨機變動約在 ±0.25% 內（另有價格取整與最低價格限制），每分鐘形成一根 K 線。目前尚未加入新聞事件、公司業績或牛熊市週期。買賣不影響價格，也不是玩家間撮合。平台提供模擬流動性，整筆成交，不做部分成交、融資或放空，手續費為零。市價單按伺服器接受請求時的價格成交；限價單觸及條件後在下一次行情更新成交。買入限價單可按更低價格成交；賣出可按更高價格成交。

漲跌百分比是相對平台初始價格，非真實交易日漲跌。首次啟動會產生 90 根示範歷史 K 線，此後累積實際模擬行情；關機期間不補行情。畫面每三秒輪詢，同時在線的玩家可能因請求時間差短暫看到不同更新批次。平台累計成交股數只統計實際執行的模擬交易。

## 資料與設定

資料位於 `data/market.db`。備份時先停止伺服器，再複製整個 `data` 資料夾。請勿刪除資料庫，否則帳號與交易紀錄會消失。

環境變數：`PORT`（預設 8088）、`HOST`（預設 127.0.0.1）、`STOCK_DB`（資料庫位置）、`COOKIE_SECURE`（HTTPS 部署時設為 1）。只啟動一個伺服器程序，避免多個行情迴圈同時更新。

```powershell

```

測試使用獨立暫存資料庫與自動分配的埠，不改動正式資料。涵蓋多帳號隔離、驗證、掛單保留、撤單權限、限價成交與並行支出。
