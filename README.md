# ORBIT 星軌交易所 · 瀏覽器單機版

繁體中文、柔和粉彩風格的虛擬股票遊戲。直接在瀏覽器執行，無須註冊、Python 後端或 Supabase，不使用任何付費服務。

## GitHub Pages 上傳

將以下內容放在儲存庫根目錄，保留 public 資料夾結構：

```
index.html
.nojekyll
README.md
public/
  index.html
  app.js
  engine.js
  storage.js
  style.css
  pastel.css
```

在 Settings → Pages 選擇從 main 分支的根目錄發布。已有 Pages 設定時，只需更新這些檔案，等待部署完成，再重新整理網站。所有資源使用相對路徑，支援 /stock-simulator/ 子路徑。

不要上傳 data/、.env、日誌、個人 JSON 存檔或資料庫。舊有 server.py、test_server.py 不供瀏覽器版使用，可留作舊版參考。github-source.zip 是打包用途，請解壓縮後上傳內容。

## 遊玩與保存

- 開啟網站即獲得 1,000,000 虛擬資金，不需要登入。
- 市價買賣、限價掛單、撤單、自選清單、持倉損益與個人成績。
- 資料以 IndexedDB 自動儲存在目前瀏覽器；瀏覽器必須允許網站儲存。
- 點右上角「單機交易者 · 存檔」可改暱稱、匯出／匯入 JSON 或重新開始。
- 清除網站資料會清除進度；無痕模式結束後也可能失去資料。請定期匯出備份。
- GitHub 網址與 localhost 各自擁有獨立存檔；換裝置或網址時可手動匯出／匯入。
- 同一網站的多個分頁使用同一份存檔，交易以資料庫交易依序處理，行情每三秒最多推進一次。
- 舊 Python 版的 SQLite 帳號、持倉不會自動轉入；舊資料庫仍保留在本機。

## 行情規則

頁面位於前景時，每三秒隨機漲跌約 ±0.25%，受價格取整與最低／最高價格限制。每分鐘形成一根 K 線，保留最近 90 根。首次啟動的歷史 K 線是示範資料。切到背景、關閉頁面、電腦休眠時不持續模擬，恢復後不補算離線行情；其他仍在前景的分頁可繼續推動同一市場。

限價單在行情觸及條件時成交；可立即成交的限價單會在下單時成交。掛單保留資金或股數，最多 100 筆。保留最近 200 筆已結束委託與全部掛單。不收手續費、不支援放空。買賣不影響股價，沒有新聞或牛熊市週期。

所有資金、公司與市場均為虛構。「單機成績」只顯示自己的進度，沒有全球排行榜。玩家可修改自己的本機資料，因此本版不能用作多人公平競賽。

## 本機預覽

如需本機預覽，安裝 Python 後雙擊 start.bat，再開啟 http://localhost:8088 。這裡的 Python 只提供靜態檔案，遊戲仍在瀏覽器中運算。網站載入後，交易與行情不需要網路；本版沒有離線網頁快取，斷網後重新開啟 GitHub 網址不保證能載入。

## 測試

安裝 Node.js 後執行 `node --test test_engine.cjs`。測試涵蓋資金保留、限價成交、撤單、禁止超賣、存檔驗證與行情時間間隔。
